✨ Two-Source Precision Model

When NIST truncates exact computable constants with ..., the API delivers the 34-digit IEEE 754 decimal128 or complete terminating rational in value while preserving the verbatim publication string in nistValue.

⏳ Per-Release SI Roles (1998–2022)

Every versioned value carries its release-specific adjustmentRole (defining, computed_exact, adjusted, computed_derived) and isComputed flag, capturing the May 2019 SI redefinition across 67 transitioning constants.

🕸️ Algebraic Formula DAG

Constants expose symbolic expressions (formula), LaTeX equations (formulaLatex), and bidirectional dependency links (derivedFrom and usedIn) across 315 physical relationships.

🛡️ IEEE 754 Storage Guidance

Each value declares significantDigits, fitsFloat32, fitsFloat64, and recommendedNumericType (float32, float64, or decimal) to prevent silent floating-point rounding in scientific code.
